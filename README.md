## 为什么叫 Kakashi

Kakashi 取自《火影忍者》里的「拷贝忍者」旗木卡卡西 —— 传说他复制过上千种忍术。

这个项目想做的事同样直白：**看到任何一个跑得通的 SaaS 业务，就把它 clone 下来。** 不限品类、不限形态，甚至不限于 SaaS —— 任何跑在线上的生意，都可以被理解、拆解、复刻。

名字是卡卡西，头像也是卡卡西。

## 想解决什么

线上生意的门槛，正在从「怎么做」变成「做什么」。

技术实现越来越便宜，真正值钱的是被市场验证过的需求、产品和商业模式。与其从零猜一个需求，不如先找到一个已经在赚钱的业务，把它完整地理解一遍，再用更低的成本、更快的速度复刻出来 —— 换一个市场、换一个人群、换一种交付方式。

Kakashi 就是这把刀：**把一个在线业务拆到可复刻的程度。**

## 大致思路

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| 探测 | 一个在线业务（官网 / 定价页 / 产品流程） | 它在卖什么、卖给谁、怎么收钱 |
| 拆解 | 上一步的公开信息 | 产品形态、商业模式、关键功能清单 |
| 复刻 | 拆解结果 | 一个能跑起来的最小可用版本 |
| 验证 | 复刻出的产品 | 上线、度量、迭代或放弃 |

> 以上是方向，不是已完成的功能。仓库目前处于初始化阶段。
